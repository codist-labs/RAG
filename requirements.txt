# ALL THREE cap protobuf below 5 — nothing in this file
# actually needs protobuf>=5. A previous pin of
# protobuf>=5.26.1,<6.0.0 was based on an incorrect assumption
# and made the whole dependency set unsatisfiable (uv correctly
# refused to resolve it: "grpcio-tools==1.62.3 depends on
# protobuf>=4.21.6,<5.0.dev0 ... your requirements are
# unsatisfiable"). The apache/airflow base image already ships
# protobuf==4.25.2, which satisfies every constraint above with
# zero extra installs — do not raise this above <5 unless you
# also bump grpcio/grpcio-tools to >=1.63.0 (the first release
# where their protobuf floor moved to >=5.26.1) AND confirm
# mlflow/streamlit have been upgraded to versions that also
# allow protobuf>=5.
